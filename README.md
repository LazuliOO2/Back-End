# Back-end

## Projetos Back-End no Repositório

### Formulário SQL com PHP
**Descrição:** Desenvolvi um formulário utilizando PHP com integração ao banco de dados SQL. O projeto permite armazenar, recuperar e manipular informações enviadas pelo usuário.

---

### Desafio da Morada (Caixa Eletrônico)
**Descrição:** Algoritmo de simulação de um caixa eletrônico desenvolvido em TypeScript. O projeto recebe o valor a ser sacado e retorna a quantidade mínima de notas necessárias para compor o valor solicitado.

---

### API Blog de Foto em JavaScript
**Descrição:** Desenvolvi uma API para gerenciamento de fotos em um blog, utilizando JavaScript. O projeto inclui testes unitários para garantir a integridade da API.
